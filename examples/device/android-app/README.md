# Android phone

Requires Node.js 22+, JDK 21 and Android SDK 35. From the repository root:

```sh
npm ci
npm run build:device-ui
./gradlew :android-example:assembleDebug
```

Install `examples/device/android-app/app/build/outputs/apk/debug/app-debug.apk`.
Open the pairing link generated by the control room, sign in, and enable remote access.
Complete Wireless Debugging pairing through the foreground notification while
the system's six-digit pairing dialog remains open.

Choose screen sharing and grant Android's whole-screen MediaProjection permission.
While sharing is active, the app pushes a JPEG preview about once per second,
including when the screen is static or Gelato is in the background; the
Controller can read the latest frame without issuing repeated screenshot
commands. Android requires a fresh system confirmation after the projection
stops or the app process restarts. Enable background access and the device
manufacturer's unrestricted battery setting for persistent use. The app also
supports phone input, on-demand diagnostic screenshots, UI trees, shell/logcat
and the bundled App automation adapters.

To update an existing install, retain its signing key and pass
`-PgalateaAndroidApplicationId=YOUR_EXISTING_APPLICATION_ID` to Gradle.
